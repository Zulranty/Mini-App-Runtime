# Project instructions

- Read the documentation in `Docs` before starting work.
- Update the documentation when a change makes it necessary.
- After changing documentation, run `Docs\MergeDocumentation.cmd`.
- Build all platforms only with `build\Scripts\BuildAll.cmd`.
- Build Android only with `build\Scripts\BuildAndroid.cmd`.
- Build Windows only with `build\Scripts\BuildWindows.cmd`.
