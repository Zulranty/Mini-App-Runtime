Модуль Telegram

В лаунчере MiniApps откройте Settings → Telegram и установите или обновите пакет. Затем вернитесь сюда.

После входа MiniApps сохранит сеанс на этом устройстве и вернёт вас в приложение, которое запросило вход.

Войдите в аккаунт, открытый в Telegram Beta с включённым Test Backend. Код или QR подтверждается в тестовом сеансе.

Вход в Telegram

Реквизиты Telegram API взяты из сборки MiniApps.

Как получить API ID и API hash
  1. Откройте my.telegram.org, введите свой номер в международном формате и подтвердите вход кодом из Telegram.
  2. Выберите API development tools. Если форма открылась впервые, придумайте название и короткое имя приложения, выберите платформу и нажмите Create application.
  3. На той же странице скопируйте App api_id в поле «API ID», а App api_hash в поле «API hash» ниже. Если приложение уже создано, используйте значения со страницы без повторной регистрации.
  4. Нажмите «Войти по QR» или укажите номер и нажмите «Получить код».
