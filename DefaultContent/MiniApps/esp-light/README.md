# ESP Light 1.3.0

Мини-аппка для MiniApp Runtime1.5.0+. Команды и интерфейс лампы находятся
только в этом пресете. Управление открыто всем клиентам с доступом к лампе,
без сопряжения и ключа. Все конфиги ESP находятся в начале MiniAppLight.ino.

## Установка

1. Импортируйте папку мини-аппки или ZIP с файлом manifest.json в корне.
2. Для лампы нужна совместимая прошивка MiniAppLight с HTTPv3. Скетч
   поставляется отдельно. При сборке задайте пароль точки доступа в
   SETUP_WIFI_PASSWORD (от 8 до 63 символов ASCII).
3. При первой настройке подключитесь к точке доступа лампы, откройте
   http://192.168.4.1 и настройте подключение к Wi-Fi. Верните компьютер или
   телефон в ту же сеть и разрешите поиск в мини-аппке.
4. Кнопка «Синхронизировать» читает текущие настройки лампы.

До подключения видны поиск/информация. После подключения — управление.
Прошивкаv2 требует обновления для нового интерфейса; базовый JS-клиент сохраняет
v2-совместимость, но новые элементы показываются только с v3.

## Режимы

- **Цвет**:16 базовых цветов на квадратных кнопках.
- **Цветовой круг**: круг на всю ширину, оттенок/насыщенность, обычный color input.
- **Радуга**: «Вперёд» — прежнее движение вдоль ленты; «Вбок» — вертикальные
  цветные полосы движутся вокруг цилиндра; «Вниз»/«Вверх» — горизонтальные
  цветные полосы опускаются/поднимаются. Пространственные варианты используют
  реальные настроенные углы и высоты LED.
- **Огонь**: два масштаба цилиндрического шума, движение вверх, непрерывный
  стык окружности, плавное охлаждение/цвет. Настройки: скорость, высота пламени,
  ширина языков, плавность, жар, цвет. «По умолчанию» восстанавливает исходные
  значения прошивки. Базовая палитра: чёрный/красный/оранжевый/жёлтый/тёплый
  белый. Пользовательский цвет меняет палитру с сохранением светлых горячих зон.
- **Кастом**: перетаскивайте цилиндр для вращения; колёсико масштабирует.
  Клик наносит цвет кисти. Повторный клик с тем же цветом гасит LED, другой цвет
  заменяет текущий. Проверка выполняется на ESP по актуальному цвету.
  «Нанести» и отдельный color input всегда устанавливают цвет, «Погасить LED»
  обнуляет выбранный LED, «Очистить» — весь рисунок. Номера UI с1, индексы API с0.
- **Таймер**: выберите часы/минуты, запустите. Лампа включается в текущем
  световом режиме и выключается через выбранное время. Диапазон1минута —
  23ч59м (или меньший MAX_TIMER_MINUTES). Отмена оставляет свет включённым;
  ручное выключение отменяет отсчёт. Таймер работает на ESP без открытой
  мини-аппки и без сети. После перезагрузки активный отсчёт отменяется:
  без RTC неизвестна длительность отключения питания. Выбранная длительность
  помнится. Это отдельная страница управления, текущий световой режим сохраняется.

## Яркость

Кнопки −/+ меняют яркость на1процентный пункт в диапазоне0..100.
Процент задаёт расчётный лимит FastLED:100%=MAX_CURRENT_MA,
50%=MAX_CURRENT_MA/2;0% гасит свет. Рядом показан лимит вмА.
Лимит — не измерение потребления: если рисунку нужно меньше тока, чем доступно,
уменьшение лимита может не изменить его вид. MAX_CURRENT_MA задаётся только
в скетче; по умолчанию500мА при5В.

## Пресеты

«Сохранить пресет» доступно во всех режимах. Задайте имя; сохраняются включение, режим,
яркость, общий цвет, направление радуги и настройки огня. В кастоме также
сохраняется рисунок. Пресет таймера дополнительно хранит выбранную длительность
и текущий световой режим. При его выборе запускается новый отсчёт и включается
свет; обычный световой пресет отменяет активный таймер.

Кнопка «Пресеты» открывает библиотеку. Можно выбирать, переименовывать и удалять.
Выбор применяет настройки одним атомарным запросом и оставляет открытой
страницу пресетов. «Управление» возвращает к режимам.
Библиотека хранится локально в storage этой мини-аппки, до100записей,
независимо на каждом ПК/телефоне. Рисунок применим к лампе с тем же числом LED.
Ошибка записи не заменяет ранее сохранённые пресеты.

## Геометрия и конфиг скетча

116 WS2812B, GPIO4, GRB,15 рядов по7–8, одно направление намотки.
ROW_STARTS={0,8,16,23,31,39,46,54,62,69,77,85,92,100,108} из ручной калибровки
sketch_jun2a. SERPENTINE=false. Радиус42мм, высота150мм.
SPIRAL_LAYOUT=true: непрерывная спираль со средним шагом116/15LED на оборот.
Это начальное приближение, а не точная геометрия, измеренная по фотографиям.

- SPIRAL_LEDS_PER_TURN — измеренный средний шаг, допускает дробное значение.
- SPIRAL_START_ANGLE_DEG — поворот всей модели.
- ROW_ANGLE_CORRECTION_DEG/ROW_HEIGHT_CORRECTION_MM — поправки витков.
- LED_ANGLE_CORRECTION_DEG/LED_HEIGHT_CORRECTION_MM — поправки физических LED.

Поправки по умолчанию0. Например,{0,-8,3} для ROW_ANGLE_CORRECTION_DEG
поворачивает второй виток на−8°, третий на+3°, остальные остаются0.
Итоговая высота должна оставаться в0..CYLINDER_HEIGHT_MM; неверные конфиги
не компилируются. Измените поправки, прошейте и синхронизируйте.
Огонь и3D-модель получают одни позиции. SPIRAL_LAYOUT=false включает кольца
с угловым шагом MATRIX_COLUMNS и возможной змейкой SERPENTINE.

FIRE_* в начале скетча задают базовые характеристики эффекта и палитру;
DEFAULT_FIRE_PERCENT/DEFAULT_FIRE_COLOR — исходные положения UI и оттенок.
WIFI_RESET_PIN удерживается3секунды для сброса Wi-Fi; проверьте GPIO кнопки
вашей платы (GPIO0 не обязательно BOOT). Питание ленты внешнее, GND общий.

## Сохранение и таймер

NVS хранит on/off, процент яркости, общий цвет, режим, направление радуги,
настройки огня, кастом и выбранную длительность таймера. Свет восстанавливается
перед ожиданием Wi-Fi. Если был выключен, остаётся выключенным.
Форматv2 читает старыйv1 с тем же LED_COUNT: состояние/рисунок сохраняются,
яркость округляется до ближайшего целого процента, новые настройки получают
дефолты. Следующая команда сохраняет новый формат. Старый120-LED снимок
несовместим с116-LED конфигом. Изменение геометрии при116 не сбрасывает данные.

Команда сначала полностью проверяется и сохраняется, затем применяется.
Повтор одинакового снимка, анимации/опрос не пишут flash. Ошибка сохранения:
HTTP503, состояние не меняется. По истечении таймера свет выключается сразу,
потом сохраняется; при ошибке записи ESP повторяет раз в секунду, оставаясь
выключенной. До успешной записи после внезапного отключения питания может
восстановиться прежний сохранённый снимок.

## HTTPv3

- GET /api/info: version3, deviceId, ledCount, maxCurrentMa, maxTimerMinutes,
  fireDefaults, effects, layout с парными anglesDeg/heightsMm по физическим индексам.
- GET /api/state: deviceId,on,brightnessPercent,currentLimitMa,color,effect,pixels,
  rainbowMode,fire{speed,height,width,smooth,intensity,color},
  timer{active,minutes,remainingSeconds}. brightness0..255 — совместимое округление.
- GET /api/sync: info иstate одним снимком.
- POST /api/state: form-urlencoded on,brightnessPercent,color,effect,rainbowMode,
  fireSpeed/fireHeight/fireWidth1..100, fireSmooth/fireIntensity0..100,
  fireColor=rrggbb, resetFire=1, timerMinutes0..MAX_TIMER_MINUTES.
  0отменяет отсчёт. resetFire нельзя смешивать с другими fire-полями.
  brightness0..255 поддержан для старых клиентов, но не вместе с brightnessPercent.
  index+pixel=rrggbb изменяет LED; toggle=1 добавляет повторное нажатие.
  pixels — полный RGB-hex для атомарного пресета, clear=1 — очистка.
  clear/pixels/index нельзя смешивать. Повторные/неверные поля дают400 без изменения.

Поиск UDP42101, сервис miniapp-light, MINIAPP_DEVICE/1. HTTP без шифрования.
Одинаковая частная IPv4-сеть и отсутствие изоляции клиентов необходимы для поиска.
Мини-аппка требует только storage/network, никаких секретных ключей.

## Проверки

node tests/client-tests.js: настоящий клиент, очередь, sync и геометрия.
node tests/preset-tests.js: библиотека, сохранение/ошибки и HTTPv3.
Из корня репозитория запустите локальный HTTP-сервер:

```powershell
python -m http.server 8938 --bind 127.0.0.1 --directory DefaultContent/MiniApps/esp-light
```

В отдельном терминале откройте сессию Playwright CLI и выполните
`playwright-cli run-code --filename=DefaultContent/MiniApps/esp-light/tests/browser-smoke.js`.
Тем же способом запустите `features-smoke.js` и `flicker-smoke.js`.
Сценарии используют сетевой симулятор и сохраняют снимки в `Output/playwright/`.
Они проверяют интерфейс и задержки команд. Внешний вид эффектов и ток
на физической лампе проверяются отдельно.
